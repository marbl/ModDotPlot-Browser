## [0.1.0] - 2026-08-28

### Added

* Entirely client-side multi-file, multi-record FASTA and gzip FASTA loading
* Independent X/Y record selection for self and pairwise comparisons
* Rust/Wasm ntHash2, OPH b-bit, HLL, containment-derived ANI backend
* Bounded detailed-only exact correction for statistically sparse cores
* Configurable quick and detailed progressive estimates with paint acknowledgement
* Responsive tiled WebGL2 rendering, pointer zoom, pan, reset, and coarse-level fallback
* Similarity and forward/reverse orientation display modes
* Three-anchor 80% to 100% identity color transfer and compact histogram
* Exact canonical k-mer terminal zoom with genome-browser base colors
* BED3-12, GFF3, and GTF axis feature tracks with record and bounds validation
* Byte-budgeted Wasm and renderer caches with compact memory reporting
* Exact, scalar, bottom-s/minmer, and MashMap-compatible reference implementations
* Rust, TypeScript, differential, statistical, and Phase 0 benchmark suites
* Design reference, user guide, privacy statement, contribution policy, and release
  checklist
* Release-facing `moddotplot-rs` project name and explicit ChatGPT 5.6 Sol/Adam
  Phillippy authorship statement
* Preferred original ModDotPlot citation plus structured method and reference credits

### Known limitations

* This is an initial functional preview, not a research-validated release.
* The contiguous in-memory representation is not approved for reliable 1 Gb records.
* Session persistence and data/image export are not implemented.
* Browser compatibility and graphics recovery need broader automated coverage.
