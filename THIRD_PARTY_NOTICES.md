# Third-party notices

The complete locked dependency inventory is generated in `SBOM.cdx.json`. License
texts discovered in every installed Cargo and npm package are bundled in
`THIRD_PARTY_LICENSES.txt`; both files are regenerated by `npm --prefix web run sbom`.

## ColorBrewer 2 color schemes

The discrete color values in `web/src/colorbrewer.ts` come from
[ColorBrewer 2](https://colorbrewer2.org/), with the published scheme data retained
locally so the application makes no runtime request. ColorBrewer is credited to
Cynthia Brewer, Mark Harrower, and The Pennsylvania State University. Its source is
maintained by Axis Maps at <https://github.com/axismaps/colorbrewer>; the scheme table,
including the nine-class YlOrRd variant, was verified against
<https://github.com/axismaps/colorbrewer/blob/master/colorbrewer_schemes.js>.

Copyright (c) 2002 Cynthia Brewer, Mark Harrower, and The Pennsylvania State University.

ColorBrewer software and color schemes are licensed under the Apache License, Version
2.0. A complete Apache-2.0 license text is included in `THIRD_PARTY_LICENSES.txt`.

## Viridis color data

The 256-color Viridis table in `web/src/palettes.ts` is adapted from
[d3-scale-chromatic 3.1.0](https://github.com/d3/d3-scale-chromatic/blob/main/src/sequential-multi/viridis.js).
The application retains the table locally and samples it into discrete 3 through
12-color variants using d3's published ramp indexing, without RGB interpolation. This
does not add a runtime d3 dependency.

Copyright 2010-2024 Mike Bostock.

d3-scale-chromatic is licensed under its ISC-style permission notice. The complete
notice is included in `D3_SCALE_CHROMATIC_LICENSE.txt` and the generated
`THIRD_PARTY_LICENSES.txt` bundle.

## ntHash2 algorithm and constants

The clean Rust/Wasm implementation in `crates/core/src/hash.rs` follows the ntHash2
split-rotation recurrence and published nucleotide seed constants. Validation vectors
are pinned to official ntHash source commit
`c26bd4572a19de81e30d55042dbd33c1fd21d4b6`.
