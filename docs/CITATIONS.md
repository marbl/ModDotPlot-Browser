## Scientific methods and reference implementations

ModDotPlot Browser relies on or was validated against the following methods and reference
implementations. Cite the relevant works when publishing analyses that depend on those
components.

### MinHash, containment, and genomic sketching

* Broder AZ. On the resemblance and containment of documents. *Compression and
  Complexity of Sequences 1997*. 1997:21-29.
  [doi:10.1109/SEQUEN.1997.666900](https://doi.org/10.1109/SEQUEN.1997.666900).
* Ondov BD, Treangen TJ, Melsted P, Mallonee AB, Bergman NH, Koren S, Phillippy AM.
  Mash: fast genome and metagenome distance estimation using MinHash. *Genome Biology*.
  2016;17:132.
  [doi:10.1186/s13059-016-0997-x](https://doi.org/10.1186/s13059-016-0997-x).

### Historical MashMap and minmer design references

* Jain C, Dilthey A, Koren S, Aluru S, Phillippy AM. A fast approximate algorithm for
  mapping long reads to large reference databases. *Journal of Computational Biology*.
  2018;25(7):766-779.
  [doi:10.1089/cmb.2018.0036](https://doi.org/10.1089/cmb.2018.0036).
* Kille B, Garrison E, Treangen TJ, Phillippy AM. Minmers are a generalization of
  minimizers that enable unbiased local Jaccard estimation. *Bioinformatics*.
  2023;39(9):btad512.
  [doi:10.1093/bioinformatics/btad512](https://doi.org/10.1093/bioinformatics/btad512).

MashMap/minmers informed the original design and Phase 0 evaluation, but are not part
of the current executable or scientific oracle. Their former reference code is
recoverable at Git tag `v0.1.0`; exact distinct canonical k-mer containment is now the
sole scientific oracle.

### Historical MurmurHash3 compatibility reference

The removed Phase 0 MashMap path was checked against Austin Appleby's public-domain
[MurmurHash3 reference implementation](https://github.com/aappleby/smhasher/blob/master/src/MurmurHash3.cpp)
and a pinned MashMap fixture. The current release compiles only ntHash2.

## Reference software

The structured metadata also credits the original
[ModDotPlot](https://github.com/marbl/moddotplot) implementation,
[MashMap](https://github.com/marbl/MashMap) commit `1a07d0e`, the
[ntHash](https://github.com/bcgsc/ntHash) source commit pinned in the test fixtures,
and the historically consulted SMHasher/MurmurHash3 reference implementation.

Similarity color schemes use [ColorBrewer 2](https://colorbrewer2.org/), created by
Cynthia Brewer, Mark Harrower, and The Pennsylvania State University. Viridis color
data are adapted from
[d3-scale-chromatic 3.1.0](https://github.com/d3/d3-scale-chromatic/blob/main/src/sequential-multi/viridis.js),
Copyright 2010-2024 Mike Bostock. The application stores these color tables locally and
makes no runtime request to either source.
