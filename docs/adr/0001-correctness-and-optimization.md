# ADR 0001: Correctness gates optimized kernels

> **Authorship note:** This document was generated by ChatGPT 5.6 Sol. The software
> was written by ChatGPT 5.6 Sol under the guidance of Adam Phillippy.

## Status

Accepted

## Context

The application will be used for scientific research. Sketching is statistical, but
coordinate assignment, hashing, window selection, containment transforms, rendering,
and provenance must be deterministic and testable. Matrix generation is also the main
performance bottleneck.

## Decision

The core contains a deliberately simple reference implementation and separately named
optimized implementations. Differential, property, fixture, and visual tests gate the
optimized path. Phase 0 chooses statistical error limits from accuracy-versus-runtime
measurements against exact k-mer sets and a pinned MashMap reference distribution.

Optimizations may alter the statistical estimator only when the change is versioned,
measured, documented, and within the accepted error envelope. They may never alter
coordinate semantics or silently change display and future-export values.

## Consequences

Some code is intentionally duplicated between reference and optimized paths. This is
accepted because independent implementations make correlated errors less likely and
make maintenance safer.
